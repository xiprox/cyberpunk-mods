# No carry weight

Adds 1000 to V's carry capacity, so carry weight practically stops mattering.
It adds to the game's base of 200, so perks, cyberware and boosters still count. 1000 rather than more keeps the menus' weight readout short.
[RECORD.md](RECORD.md) says where it stands.

## Installing

It needs TweakXL. The folder is laid out like the game folder: copy `r6` over it, which puts `nocarryweight.yaml` in `r6/tweaks/nocarryweight/`.
The crew gets it through the log collector's Mods tab. It hooks nothing and isn't data NightCoop relies on, so in co-op it only helps the players who have it.
